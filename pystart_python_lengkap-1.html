🎯 Misi pertama: pahami input()

Kamu tadi sedang belajar input(). Intinya: Python berhenti sebentar untuk menunggu pengguna mengetik sesuatu.

nama = input("Masukkan nama: ") print("Halo", nama)
Kalau muncul Masukkan nama:, itu bukan error. Program memang sedang menunggu kamu mengetik lalu menekan Enter.

🗺️ Roadmap Python

Level 1 — Dasar

print → comment → variabel → tipe data → input → operator

Level 2 — Logika

if/elif/else → perbandingan → logika AND/OR/NOT

Level 3 — Perulangan

for → range → while → break/continue

Level 4 — Data

list → tuple → dictionary → set → string

Level 5 — Struktur program

fungsi → parameter → return → module → error handling

Level 6 — Project

Kalkulator → tebak angka → data siswa → aplikasi sederhana.
